## Tiếng Việt

### Tải tệp lớn không còn dừng vì link hết hạn
- Một số trang (Hugging Face, GitHub Releases…) chuyển link tải sang một link tạm chỉ dùng được trong một thời gian. Trước đây khi tải tệp lớn quá thời gian đó, DoMa báo "Link đã hết hạn" và dừng lại. Giờ DoMa tự xin link mới từ link gốc rồi tải tiếp, bạn không phải bấm gì.

## English

### Large downloads no longer stop when the link expires
- Some sites (Hugging Face, GitHub Releases…) redirect to a temporary link that only works for a limited time. Previously, when a large file took longer than that, DoMa reported "The link has expired" and stopped. DoMa now fetches a new link from the original address and continues on its own.
