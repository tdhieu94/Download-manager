## Tiếng Việt

### Sửa lỗi
- Sửa lỗi bấm **Yes** để cài công cụ tải YouTube nhưng báo "Không tải được công cụ YouTube": DoMa giờ đi theo đúng link chuyển hướng của GitHub khi tải yt-dlp và ffmpeg.
- Trong lúc cài công cụ, trỏ chuột vào biểu tượng DoMa ở khay để xem đã tải được bao nhiêu phần trăm.

## English

### Fixes
- Fixed clicking **Yes** to install the YouTube tools ending with "Không tải được công cụ YouTube" (Could not download the YouTube tools): DoMa now follows GitHub's download redirects when fetching yt-dlp and ffmpeg.
- While the tools install, hover over the DoMa tray icon to see the download percentage.
