## Tiếng Việt

### Giao diện
- Menu chuột phải và menu ở khay hệ thống: chữ và icon giờ được căn giữa thẳng hàng, không còn bị lệch.
- Di chuột vào tệp không còn hiện vị trí lưu và đường link.
- Bỏ khung viền tối quanh các nút (ví dụ các nút trong dải thông báo cập nhật).

### Tính năng mới
- **Mở trang nguồn** trong menu chuột phải: mở lại trang web nơi bạn đã tải tệp (hoặc link tải nếu không có trang nguồn).

## English

### Interface
- Right-click and tray menus: text and icons are now vertically centered and aligned.
- Hovering a file no longer shows its save location and link.
- Removed the dark frame around buttons (e.g. in the update banner).

### New
- **Open source page** in the right-click menu: reopens the web page the file was downloaded from (or the download link if there is none).
