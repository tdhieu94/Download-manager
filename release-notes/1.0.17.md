## Tiếng Việt

### Dán link trang GitHub vẫn tải được
- Dán link trang xem một tệp trên GitHub (dạng `github.com/…/blob/…`) thì DoMa tự đổi sang tệp gốc và tải về, thay vì báo không tải được.
- Dán link trang kho mã (`github.com/tên/kho`) hoặc trang một nhánh, một tag (`…/tree/v1.2`) thì DoMa tải tệp .zip mã nguồn tương ứng.
- Link tệp đính kèm trong mục Releases vẫn tải như trước. Riêng link *trang* Releases thì chưa đổi tự động được: hãy bấm chuột phải vào tệp cần tải › **Sao chép địa chỉ liên kết** rồi dán vào DoMa.

### Báo lỗi rõ hơn khi dán link không tải được
- Thay cho câu "Không tải được link này", DoMa nói rõ lý do và cách xử lý: link mở ra một trang web chứ không phải tệp, không tìm thấy tệp (404), cần đăng nhập hoặc link hết hạn, không kết nối được máy chủ, hoặc mã lỗi máy chủ trả về.

## English

### Pasted GitHub page links now download
- Paste the link of a file view page on GitHub (`github.com/…/blob/…`) and DoMa switches to the raw file and downloads it instead of reporting a failure.
- Paste a repository link (`github.com/owner/repo`) or a branch or tag page (`…/tree/v1.2`) and DoMa downloads the matching source .zip.
- Release asset links work as before. A Releases *page* link is still not converted: right-click the file you want › **Copy link address**, then paste it into DoMa.

### Clearer errors for links that cannot be downloaded
- Instead of "Could not download this link", DoMa now states the reason and what to do: the link opens a web page rather than a file, the file was not found (404), sign-in is required or the link expired, the server could not be reached, or the error code the server returned.
