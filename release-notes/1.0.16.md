## Tiếng Việt

### Tải qua proxy
- **Cài đặt** › **Mạng** › **Proxy**: nhập địa chỉ proxy HTTP hoặc SOCKS5, ví dụ `http://127.0.0.1:8080` hoặc `socks5://127.0.0.1:1080`. Để trống thì DoMa theo cài đặt proxy của Windows như trước.
- Proxy áp dụng cho tải tệp, tải video từ trang (YouTube, Facebook…), kiểm tra cập nhật, và có hiệu lực ngay với các lượt tải mới. Torrent chỉ dùng được proxy HTTP (cho phần tải tệp .torrent và tracker).

### Giới hạn tốc độ tuỳ ý cho từng tệp
- Chuột phải › **Giới hạn tốc độ tệp này** › **Mức khác…** để nhập mức bất kỳ, ví dụ `750` (KB/s) hoặc `1.5 MB`.

### Thử lại các tệp lỗi một lượt
- Nút **Tốc độ và lịch** › **Thử lại các tệp lỗi** cho chạy lại mọi tệp đang báo lỗi.

### Sửa lỗi
- Bấm **Lưu** trong Cài đặt không còn làm DoMa quên chất lượng video và lựa chọn phụ đề bạn đã chọn lần trước.

## English

### Download through a proxy
- **Settings** › **Network** › **Proxy**: enter an HTTP or SOCKS5 proxy, e.g. `http://127.0.0.1:8080` or `socks5://127.0.0.1:1080`. Leave it empty and DoMa follows the Windows proxy settings as before.
- The proxy is used for file downloads, page videos (YouTube, Facebook…) and update checks, and applies to new downloads right away. Torrents can only use an HTTP proxy (for the .torrent file and trackers).

### Any speed limit per file
- Right-click › **Limit this file's speed** › **Other…** to type any limit, e.g. `750` (KB/s) or `1.5 MB`.

### Retry all failed files
- **Speed and schedule** › **Retry failed files** restarts every file that currently shows an error.

### Fixes
- Clicking **Save** in Settings no longer makes DoMa forget the video quality and subtitle choice you picked last time.
