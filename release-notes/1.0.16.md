## Tiếng Việt

### Tải qua proxy
- **Cài đặt** › **Mạng** › **Proxy**: nhập địa chỉ proxy HTTP hoặc SOCKS5, ví dụ `http://127.0.0.1:8080` hoặc `socks5://127.0.0.1:1080`. Để trống thì DoMa theo cài đặt proxy của Windows như trước.
- Proxy áp dụng cho tải tệp, tải video từ trang (YouTube, Facebook…), kiểm tra cập nhật, và có hiệu lực ngay với các lượt tải mới. Torrent chỉ dùng được proxy HTTP (cho phần tải tệp .torrent và tracker).

### Giới hạn tốc độ tuỳ ý cho từng tệp
- Chuột phải › **Giới hạn tốc độ tệp này** › **Mức khác…** để nhập mức bất kỳ, ví dụ `750` (KB/s) hoặc `1.5 MB`.

### Thử lại các tệp lỗi một lượt
- Nút **Tốc độ và lịch** › **Thử lại các tệp lỗi** cho chạy lại mọi tệp đang báo lỗi.

### Sắp xếp danh sách theo cột
- Bấm tiêu đề cột **Tên file**, **Dung lượng**, **Tiến độ**, **Thời gian** hoặc **Trạng thái** để sắp xếp. Bấm lần nữa để đảo chiều, bấm lần thứ ba để về mặc định (tệp mới thêm ở trên cùng).

### Xuất link ra tệp
- Chọn một hoặc nhiều tệp, chuột phải › **Xuất link ra tệp .txt…**. Tệp này nhập lại được bằng **Thêm link** › **Nhập từ tệp .txt…**, tiện khi chuyển sang máy khác.

### Sao lưu và khôi phục
- **Cài đặt** › **Danh sách và sao lưu** › **Sao lưu…** ghi cài đặt, danh sách tải và các kênh đang theo dõi ra một tệp .zip. Trên máy mới (hoặc sau khi cài lại Windows), bấm **Khôi phục…** rồi mở lại DoMa.
- Cookie đăng nhập của các lượt tải dở không dùng được trên máy khác; nếu link cần đăng nhập, hãy dùng **Làm mới link**.

### Tự dọn danh sách
- **Cài đặt** › **Danh sách và sao lưu**: đặt số ngày để DoMa tự bỏ tệp đã tải xong khỏi danh sách (tệp trên ổ đĩa vẫn giữ nguyên). Mặc định là 0, tức giữ mãi.

### Sửa lỗi
- Bấm **Lưu** trong Cài đặt không còn làm DoMa quên chất lượng video và lựa chọn phụ đề bạn đã chọn lần trước.

## English

### Download through a proxy
- **Settings** › **Network** › **Proxy**: enter an HTTP or SOCKS5 proxy, e.g. `http://127.0.0.1:8080` or `socks5://127.0.0.1:1080`. Leave it empty and DoMa follows the Windows proxy settings as before.
- The proxy is used for file downloads, page videos (YouTube, Facebook…) and update checks, and applies to new downloads right away. Torrents can only use an HTTP proxy (for the .torrent file and trackers).

### Any speed limit per file
- Right-click › **Limit this file's speed** › **Other…** to type any limit, e.g. `750` (KB/s) or `1.5 MB`.

### Retry all failed files
- **Speed and schedule** › **Retry failed files** restarts every file that currently shows an error.

### Sort the list by column
- Click the **File name**, **Size**, **Progress**, **Time** or **Status** header to sort. Click again to reverse, and a third time to return to the default (newest on top).

### Export links to a file
- Select one or more files, right-click › **Export links to a .txt file…**. The file can be imported again with **Add link** › **Import from .txt file…**, handy when moving to another computer.

### Backup and restore
- **Settings** › **List and backup** › **Back up…** saves your settings, download list and followed channels to a .zip file. On a new computer (or after reinstalling Windows), click **Restore…** and reopen DoMa.
- Sign-in cookies of unfinished downloads don't work on another computer; if a link needs sign-in, use **Refresh link**.

### Automatic list clean-up
- **Settings** › **List and backup**: set a number of days after which DoMa removes finished files from the list (files on disk are kept). The default is 0, meaning keep forever.

### Fixes
- Clicking **Save** in Settings no longer makes DoMa forget the video quality and subtitle choice you picked last time.
